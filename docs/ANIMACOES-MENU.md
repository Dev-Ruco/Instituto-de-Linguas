# Microinteracções do menu

- Hover em computadores: os itens sobem 3 px e o sublinhado amarelo surge suavemente.
- Clique: efeito de pressão discreto.
- Página activa: texto azul, sublinhado amarelo e atributo acessível `aria-current="page"`.
- Menu móvel: realce de fundo, recuo do texto e linha amarela no item activo.
- Teclado: contorno de foco visível.
- Redução de movimento: desactiva transições e transformações.

A solução usa CSS e o componente de navegação já existente, sem dependências adicionais.
