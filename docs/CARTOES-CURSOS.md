# Cartões dos cursos — bandeiras

A pedido do proponente, a área superior dos cartões usa bandeiras em vez de fotografias ou ilustrações.

Correspondências visuais: Inglês → Reino Unido, Francês → França, Português → Portugal, Línguas Moçambicanas → Moçambique, Língua e Cultura Chinesa → China.

Preparação para Exames não corresponde a um país: utiliza um símbolo académico neutro.

Bandeiras são referências gráficas convencionais, não reivindicações de origem exclusiva de cada língua.

A composição mantém a opção B: área visual 16:10, conteúdo em branco, categoria, título, descrição e ligação, com responsividade existente. A bandeira de cada curso é configurada em `src/lib/conteudos.ts`.
