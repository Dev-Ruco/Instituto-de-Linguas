# Fotografias panorâmicas dos cursos
A página de detalhe `/cursos/[slug]` usa fotografias panorâmicas ilustrativas com gradiente claro e maior protecção do texto à esquerda.

Colocar os ficheiros em `public/images/cursos/` com os nomes exactos:

- `ingles-londres.jpg`
- `frances-paris.jpg`
- `portugues-lisboa.jpg`
- `chines-muralha.jpg`
- `mocambicanas-maputo.jpg`

Preparação para Exames mantém o fundo institucional neutro. As imagens são ilustrativas, não fotografias oficiais dos edifícios ou das aulas do Instituto. O fundo azul-claro continua visível se os ficheiros estiverem ausentes.

Após carregamento das imagens, validar a legibilidade dos títulos em computador e telemóvel. Não alterar os nomes dos ficheiros sem actualizar a correspondência na página de detalhe.
